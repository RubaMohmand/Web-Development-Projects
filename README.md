# Web Development Projects

A collection of standalone front-end builds — plain HTML, CSS and JavaScript, no build step.
Open any project's `index.html` in a browser to view it.

## Projects

### I Built a Futuristic 3D Glass Card UI | Neon + Parallax Web Design
**Lowpass** — a small-room mixing guide. Dark neon layout with a glass signal board and a
keyboard/swipe-steppable engineer's deck, responsive from phone to desktop.
`index.html` · `style.css` · `script.js`

### Liquid Glass + Marquee Animation | Futuristic Web Design
**NEURAL** — a futuristic tech landing page built around a liquid-glass hero and a
continuous marquee animation.
`index.html` · `style.css` · `script.js`

### This CSS Heart Looks WAY Too Good 🔥 | HTML & CSS
**ruba.codes** — a creative digital card with a pure-CSS heart, gradient glow and
mask-composite border effects. Single self-contained file.
`index.html`

## Running locally

```bash
git clone git@github.com:RubaMohmand/Web-Development-Projects.git
cd Web-Development-Projects
open "Liquid Glass + Marquee Animation | Futuristic Web Design/index.html"
```
